How to format your CSV

Export a UTF-8, comma-separated CSV with these headers and one question per row. Header names are case-insensitive and columns may be in any order. All four fields must be filled in.

Question,Type,Reference,Answer
Example question text,General,John 1:1,Example answer
  • Type: General, According-To, Situation, In-What-Book-and-Chapter, Quote, Reference, Verse, or Context.
  • Reference: use a book name followed by a chapter, such as John 1:1 or 1 John 3:16, so chapter filtering works.
  • Wrap fields containing commas, line breaks, or double quotes in double quotes. Escape a double quote by doubling it: "A comma, and a ""quote""". Spreadsheet CSV export handles this for you.

Uploads are limited to 10 MB including form data. Invalid or incomplete rows are skipped; a file with no valid questions is rejected. A standard set also needs enough questions of each required type in the selected chapters; smaller pools can use Custom mode.
